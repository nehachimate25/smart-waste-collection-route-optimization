Smart Waste Collection Management

Intelligent Route Optimization Using Data Structures and Algorithms

Report a waste bin's location and fill level, and the system automatically works out its priority, plans an optimized collection route using a Graph, Priority Queue, Min Heap, and Dijkstra's algorithm, and hands it to a collector to execute stop by stop. The map (Leaflet + OpenStreetMap, no API key needed) only visualizes locations and routes - every distance calculation and every routing decision happens in this application's own Python code.
